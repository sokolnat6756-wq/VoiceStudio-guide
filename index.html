02 / подготовка

Проверь компьютер

Для обычного Windows-установщика Python, Node, Git, Bun и Cursor не требуются — приложение подготовит собственную ИИ-среду при первом запуске.

КомпонентНужно / желательно
WindowsWindows 10 или 11, x64. ARM64 — экспериментально.
ДискОфициальный ориентир ~10 ГБ для базовой среды и моделей. Практично резервировать 25–40 ГБ под расширение.
ОЗУ16 ГБ и больше предпочтительно, особенно при крупных моделях.
GPUNVIDIA CUDA — ускорение; CPU тоже поддерживается, но медленнее.
ИнтернетДля установщика, Python-библиотек и загрузки весов моделей. После загрузки локальные функции могут работать офлайн.
Аккаунты / оплатаДля локальной базовой версии аккаунт и подписка не нужны. Токен Hugging Face — опционален.
Если у тебя RTX 4050: на ноутбуках она обычно имеет 6 ГБ VRAM — это примерно рекомендуемый минимум обычного OmniVoice. Оставь автоматическую CUDA-настройку, а при нехватке памяти попробуй OmniVoice GGUF.

02

Проверь подлинность файла по SHA-256

Не запускай установщик до проверки

  1. Открой меню «Пуск» и найди PowerShell.
  2. Вставь команду ниже и нажми Enter.
  3. Сравни выведенный хеш с контрольной суммой релиза.
PowerShell · если файл лежит в Загрузках
Get-FileHash "$env:USERPROFILE\Downloads\VoiceStudio-0.5.8-win-x64.exe" -Algorithm SHA256

Ожидаемый SHA-256:

11238cb8b08ea38b9b4e8e3050cd950ee2a2d3af1856d54e5ce6fb877444ad34

Пока не проверено.

Если файл скачан в другую папку, в PowerShell набери Get-FileHash , затем перетащи файл в окно PowerShell и допиши -Algorithm SHA256. Совпадение суммы удостоверяет соответствие файлу релиза, но не гарантирует абсолютную безопасность кода.

03

Запусти мастер установки

У Windows-сборки v0.5.8 нет цифровой подписи

Дважды нажми на проверенный файл. Выбери папку установки и заверши мастер. Обычно приложение устанавливается для текущего пользователя, без прав администратора.

По окончании установки найди VoiceStudio в меню «Пуск» и открой приложение.

04

Выбери место для ИИ-среды

Первый запуск = отдельная настройка локального backend

На экране первого запуска найди строку App environment и кнопку Change…. Если есть диск D, удобно указать папку D:\VoiceStudio\Runtime (создай её при необходимости). Это помогает не забивать системный диск C.

Приложение подготовит Python, FFmpeg, библиотеки и связанные каталоги. Для установки отдельных движков понадобится дополнительное место. Не выбирай синхронизируемую папку OneDrive/Dropbox.

Нет диска D? Оставь предложенный приложением путь на C — это допустимо при достаточном свободном месте. Не нужно вручную переносить служебные файлы во время установки.

05

Запусти первичную установку Python и библиотек

Автоматически, без Cursor и Git

На первом экране нажми кнопку запуска настройки (Setup / Start setup, название может отличаться). Система загрузит зависимости. Требуемое свободное место для runtime ориентировочно 5 ГиБ при CPU-сборке и около 9 ГиБ при остальных вариантах, без учёта отдельных моделей.

Для NVIDIA с совместимым драйвером установщик обычно подбирает CUDA автоматически; без NVIDIA использует CPU-вариант. Не закрывай программу, пока процесс не завершится или пока не появится конкретная ошибка.

06

Проверь, видит ли программа видеокарту

Не путай название GPU в Windows с фактическим ускорением модели

  1. Открой Settings → Performance → GPU acceleration.
  2. Посмотри, определилась ли NVIDIA и какой вычислительный backend доступен: CUDA либо CPU.
  3. Если GPU не используется, проверь драйвер NVIDIA и совместимость выбранного движка. Для первого запуска можно продолжить на CPU.

Программа способна показывать видеокарту в списке устройств, даже если конкретная модель выполняется на CPU. Ориентируйся на статус движка.

Следующий шаг →
07

Выбери речевой движок

Сначала один, не скачивай всё подряд

Открой Model Catalogue. Найди раздел речевых движков (TTS / Engines). Для первого эксперимента есть два разумных варианта:

  • OmniVoice — основной движок клонирования и широкой языковой поддержки; рекомендуемый порог для NVIDIA — около 6 ГБ VRAM.
  • OmniVoice GGUF — облегчённый вариант для небольших видеокарт/CPU; может работать через Vulkan в поддерживаемых конфигурациях.

В каталоге нажми установку нужной модели/весов и проверь размер загрузки, лицензию и доступное место. Для RTX 4050 можно начать со стандартного OmniVoice, а при торможении перейти на GGUF.

Юридическая проверка: веса основного OmniVoice отмечены авторами как CC-BY-NC. Для роликов с рекламой, платных уроков и других коммерческих результатов не предполагаем разрешение автоматически — смотри условия модели в Model Catalogue.

08

Скачай веса выбранной модели

Модель — отдельная загрузка, не входит целиком в установщик

Нажми Install / Download у выбранного движка или его весов. Дождись завершения и убедись, что статус модели стал Installed / Ready. Некоторые движки устанавливают ещё собственное окружение Python.

Если Hugging Face ограничивает загрузку, можно завести бесплатный аккаунт и токен с правами Read: huggingface.co/settings/tokens. Затем открыть Settings → Credentials, вставить токен, выбрать Save и Test now.

Токен опционален для большинства публичных моделей; закрытые/gated модели могут требовать отдельного принятия лицензии. Никогда не вставляй токен в общедоступные скриншоты или сообщения.

09

Подготовь чистый образец своего голоса

Начни с 3–10 секунд без музыки и фонового шума

Запиши небольшой фрагмент своим голосом в тихом помещении. Говори ровно и чётко, без эха, фоновой музыки и чужих голосов. Сохрани файл в поддерживаемом аудиоформате (например WAV).

Выбирай голос, на использование которого у тебя есть право или согласие. Если программа попросит референс-транскрипт, введи дословно произнесённые в образце слова. Для клонирования чужих голосов требуется разрешение.

10

Сделай первую русскую озвучку

Открой Voice Cloning и сгенерируй короткий тест

  1. Открой Voice Cloning (Clone) и загрузи свой референс.
  2. Выбери Russian (ru) для текста генерации и движок, поддерживающий русский.
  3. Вставь тест ниже, затем нажми кнопку синтеза / Generate.
  4. Прослушай результат и проверь естественность, ударения, паузы и сходство с исходным голосом.
Тестовый текст · русский язык
Привет! Это моя первая озвучка в VoiceStudio. Я создаю речь с помощью искусственного интеллекта прямо на своём компьютере.

Если стандартный голос слишком медленный, в каталоге попробуй OmniVoice GGUF. Слово «русский» в интерфейсе не гарантирует идеальную дикцию — обязательно слушай результат.

11

Сохрани озвучку и голосовой профиль

Готовый WAV подходит для монтажа и архивирования

Сохрани полученный аудиофайл через Export / Download в интерфейсе. Для монтажа удобно выбрать WAV 16-bit; если нужно последующее редактирование аудио, у некоторых движков доступны 24-bit PCM или 32-bit float. Более высокая точность экспортного WAV сама по себе не делает голос качественнее.

Сохрани профиль своего голоса для повторных генераций и запиши, на каком движке и с какими настройками он получился лучше всего.

12

Пройди самопроверку и проверь файлы

Финиш — убедиться, что программа действительно работает

  1. Открой Settings → About → Run self-check.
  2. Проверь сообщения о среде, FFmpeg, свободном месте, устройстве и моделях.
  3. Прослушай экспортированный файл вне VoiceStudio, например в обычном проигрывателе.
  4. Убедись, что знаешь, где лежат твои проекты, профили и скачанные модели: Settings → Storage.
  5. При необходимости запусти программу заново и повтори короткую озвучку.

04 / интерактив

Какую модель выбрать под железо?

Выбери тип видеокарты. Это ориентир для первого теста, а не автоматическое определение твоего устройства или гарантия результата.

06 / если что-то пошло не так

Решение частых ошибок

Напиши ключевое слово в поиске или открой нужный пункт. Если система показывает код ошибки, сверяй его с официальным разделом устранения неполадок.

SmartScreen или антивирус не позволяет открыть EXE

Версия v0.5.8 для Windows опубликована без цифровой подписи. Сначала проверь путь загрузки и SHA-256 файла. Если защита блокирует запуск Python после установки, посмотри код ошибки в приложении и документацию. Не отключай защиту целиком; решение о запуске неподписанного ПО принимай осознанно.

Нет места или диск C заполняется

На первом экране выбери другую папку через Change… → App environment. Для уже установленного приложения смотри Settings → Storage. Дополнительные движки могут потребовать много гигабайт, и перенос старых сред не всегда автоматический. Не удаляй вручную чужие папки и не переноси рабочий каталог во время генерации.

CUDA out of memory / генерация зависает

Закрой игры и другие GPU-приложения, попробуй короткий текст и OmniVoice GGUF. У стандартного OmniVoice рекомендуемый минимум ~6 ГБ VRAM. Для отдельных движков ошибка может быть связана с компиляцией Triton; в Settings → Performance предусмотрена опция Disable torch.compile. Она уменьшает риск проблем, но может снизить производительность.

Модель не загружается с Hugging Face

Проверь интернет и доступ к huggingface.co, свободное место и сообщения каталога. При необходимости создай токен с правами Read и добавь в Settings → Credentials. Некоторые модели требуют принять лицензию на сайте. Не скачивай модели со случайных зеркал и не публикуй токен.

Голос плохо говорит по-русски

Проверь, что выбран Russian (ru) и конкретный движок поддерживает язык. Для клона используй чистую запись 3–10 секунд. Проверь текст, ударения, качество образца, при необходимости попробуй другой разрешённый движок. Заявленные 646 языков относятся к каталогу OmniVoice, а не к одинаковому качеству всех моделей.

Не клонируется голос или просит транскрипт

Используй чистый отрывок и при запросе введи дословный текст аудиообразца, а не текст будущей озвучки. Для стандартного OmniVoice с длинными референсами может понадобиться установленная модель распознавания речи. Самый простой тест — короткий 3–10-секундный фрагмент без музыки.

Ошибка Python / EPERM / EACCES / spawn UNKNOWN

Это может быть отказ Windows или защитного ПО запускать локальную среду. Открой Settings → About → Run self-check (если доступно), запиши код и проверь официальный раздел troubleshooting. Не предлагай системе запускать случайно найденный Python-файл вручную и не удаляй установленные проекты.

Дубляж не переводит или результат отличается по таймингам

Проверь выбранный переводчик в Settings → Models → Translation provider, установленную распознающую модель, текст сегментов и выбранный голос. Некоторые переводчики облачные, поэтому не вся цепочка дубляжа обязательно выполняется офлайн. Прослушай сегменты до экспорта.

Локальный API на localhost:3900 не отвечает

Убедись, что VoiceStudio запущен и backend завершил первичную настройку. Адрес http://localhost:3900 — стандартный, но может меняться настройками. Не открывай этот порт в публичный интернет без соответствующей аутентификации и защиты.

Появилась новая версия и нужно обновиться

Проверь официальный последний релиз. Перед обновлением сделай копии важных исходных аудиозаписей и экспортированных файлов. Параметры и модели обычно сохраняются, но лучше проверить инструкции к конкретному релизу.

Ничего не найдено. Попробуй другой запрос или открой официальную документацию.

07 / ограничения, которые нельзя пропустить

Бесплатно ≠ всё разрешено для рекламы

VoiceStudio как приложение — open source под AGPL-3.0. Но права на веса, токенизаторы и генерируемый контент определяются отдельно для каждой модели.

08 / по желанию

Как подключить к Cursor и ИИ-агентам

Это уже второй уровень — после успешной ручной озвучки. Не путай установку программы с добавлением агентского навыка.

Для обычного пользователя

EXE → первая настройка → модель → голос. Cursor и дополнительные навыки не нужны.

Для автоматизации

Запущенный VoiceStudio → локальный API/MCP → агент, который умеет отправлять запросы и забирать аудио.

Вариант 1. Установить навык VoiceStudio в агент

В терминале проекта Cursor, где установлен Node.js/npm, можно вызвать команду из официальной инструкции. Она добавляет навык для агента, а не само приложение.

PowerShell / терминал Cursor
npx skills add debpalash/VoiceStudio

Просмотри, что установщик предлагает добавить и в какой инструмент. Отдельный навык находится здесь: skills/voicestudio/SKILL.md.

Вариант 2. Подключиться через MCP/API

Если VoiceStudio уже запущен с backend по стандартному адресу:

Локальная проверка в браузере
http://localhost:3900/health

Стандартный адрес MCP: http://localhost:3900/mcp. Его подключают через поддерживаемый клиент с подходящим HTTP-транспортом. Формат MCP-конфигурации зависит от версии клиента; не вставляй произвольный JSON без проверки документации Cursor. Для запросов API возможна аутентификация: не отключай её ради удобства.

Что лежит в той самой папке .agents?

На момент проверки в .agents/skills находятся навыки fastapi-python и vite: правила разработки серверной и веб-части проекта. Для создания голоса их скачивать отдельно не нужно. Если же хочешь менять исходники приложения, это уже другой маршрут с Git, Node.js 22.12+, Bun, uv, Rust и C++ Build Tools.

Идея на будущее: сначала создай эталонный голос и проверь права на модель, затем можно интегрировать локальную озвучку через API в собственный монтажный или образовательный проект. Не рассчитывай, что любой рабочий процесс автоматически будет полностью офлайн.
